# Banco de preguntas DPO-PRO para precarga
> Documento técnico generado a partir del formulario DPO_PRO 5.0, el formulario Gestión de recursos y la clave de puntuación del libro DPO Express V 6.0. No modificar el texto de los reactivos dentro de una versión publicada.
## Resumen
- 12 campos de control estadístico.
- 168 preguntas pareadas: 96 pares positivos y 72 pares negativos.
- 336 afirmaciones pareadas.
- 25 preguntas Likert suministradas.
- 205 bloques visibles para el participante si las cuatro secciones se integran en una sola aplicación.
## Reglas de respuesta para los pares
Cada par contiene dos afirmaciones. Ambas son obligatorias: una debe quedar marcada como **Me identifico más (Mayormente cierto)** y la otra como **Me identifico menos (Mayormente falso)**. La aplicación puede almacenar únicamente el identificador de la afirmación elegida como “Más”, porque la otra queda implícitamente como “Menos”.

1. El documento de estructura menciona 31 preguntas Likert, pero el formulario suministrado contiene 25. No inventar las seis faltantes.
2. La puntuación de las 25 preguntas Likert no está definida en el libro suministrado. Precargarlas como contenido, pero mantener el cálculo desactivado hasta recibir matriz, pesos y norma.
3. El texto, orden, polaridad, peso y asignación a escala de los 336 reactivos pareados pertenecen a una versión inmutable de la clave. Cualquier cambio debe crear una nueva versión.
