Paquete de implementación para construir Report Studio y precargar la primera plantilla DPO-PPF.

- mapa completo de las 63 páginas del PDF de referencia;
- texto extraído página por página;
- plantilla `DPO-PPF v1` en JSON;
- tema Crevantia;
- biblioteca de componentes;
- presets de páginas/gráficas;
- clasificaciones;
- bindings confirmados;
- bindings no demostrados marcados como configurables;

- PDFs fuente para comparación visual;
- especificación de QA y publicación.
