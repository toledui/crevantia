## Patrones visuales identificados en el PDF
- P10: radar triangular + escala de 10 celdas.
- P16: dos escalas + cuadrantes XY + tabla de cuadrante.
- P24: tabla de 8 factores.
- P27: radar pentagonal de habilidad.
- P31: radar pentagonal de potencial.
- P33: radar doble + matriz habilidad/potencial.
- P57: matriz resumen principal.
- P58: matriz de 20 precursores.

Todos los charts se implementan en SVG.
