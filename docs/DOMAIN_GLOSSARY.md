# Glosario de dominio

- **Prueba (`Test`)**: definición comercial y lógica general de un instrumento evaluativo.
- **Versión de prueba (`TestVersion`)**: contenido inmutable de una prueba en un momento concreto.
- **Sección (`Section`)**: agrupación ordenada de instrucciones y reactivos dentro de una versión.
- **Pregunta (`Question`)**: reactivo versionado que solicita una respuesta.
- **Asignación (`Assignment`)**: derecho individual, comprado u otorgado, para realizar una prueba.
- **Intento (`Attempt`)**: ejecución concreta del cuestionario asociada a una asignación.
- **Respuesta (`Response`)**: valor persistido para una pregunta durante un intento.
- **Respuesta pareada (`PairResponse`)**: selección atómica de afirmación “más” y “menos”.
- **Calificación (`ScoringRun`)**: ejecución versionada e idempotente del motor sobre un intento enviado.
- **Norma (`Norm`)**: conjunto versionado de referencias para transformar o contextualizar puntuaciones.
- **Matriz (`Matrix`)**: estructura versionada usada por reglas explícitas del motor.
- **Resultado (`Result`)**: snapshot inmutable de la salida producida por una calificación.
- **Reporte (`GeneratedReport`)**: documento privado generado desde un resultado y una plantilla versionada.
- **Compra (`Order`)**: operación comercial independiente del derecho de aplicación.
- **Sesión (`Session`)**: vínculo de autenticación revocable que contiene un refresh token rotatorio hasheado.
