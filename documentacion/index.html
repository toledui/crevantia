Versión del manual · agosto de 2026

Guía completa de Crevantia

Todo lo necesario para utilizar, administrar y mantener la plataforma de evaluaciones: desde crear una cuenta y realizar una prueba hasta publicar instrumentos, configurar pagos y generar reportes.

Este manual describe las funciones implementadas en el sistema. Los contenidos psicométricos de ejemplo no constituyen normas, fórmulas ni interpretaciones validadas.

¿Por dónde empezar?
  • Si eres participante: crea tu cuenta, adquiere o recibe una evaluación y contéstala.
  • Si administras la plataforma: revisa el centro de control y sigue el flujo de usuarios → asignaciones → resultados.
  • Si configuras el sistema: consulta Configuración y la guía técnica.

Visión general

Mapa del sistema

Crevantia conecta un catálogo comercial con la aplicación controlada de pruebas y la consulta de resultados. Cada compra o asignación crea el derecho de realizar una prueba; cada intento conserva sus respuestas y genera un resultado independiente.

Área pública

Inicio, catálogo, contacto, registro, inicio de sesión, recuperación de contraseña y documentos legales.

Panel de usuario

Perfil, evaluaciones disponibles, compras, inicio de pruebas y consulta de resultados propios.

Administración

Usuarios, contenido de pruebas, operación, resultados, normas, comercio, reportes y ajustes.

Servicios de soporte

Correo SMTP, Stripe, documentos legales, identidad visual, salud del servidor y auditoría.

Flujo principal

Producto → Compra o asignación → Intento → Resultado → Reporte PDF. Una prueba publicada y sus versiones se conservan para que el historial sea reproducible.

Usuario

Acceso, registro y perfil

Crear una cuenta

  1. En la página inicial selecciona Crear cuenta o continúa desde el proceso de compra.
  2. Captura tus datos y una contraseña segura. Al registrarte, la cuenta queda pendiente de validación.
  3. Abre el correo de confirmación y usa el enlace dentro de las siguientes 24 horas.
  4. Vuelve a Iniciar sesión. Si no recibiste el mensaje, usa la opción para reenviar la verificación.
Importante. Si el correo no está configurado aún, la cuenta puede crearse pero no se activará hasta que se solicite un nuevo enlace después de habilitar SMTP.

Iniciar sesión y cerrar sesión

Usa el correo y contraseña registrados. La sesión se mantiene de forma segura mediante un token de renovación en el navegador; usa Cerrar sesión al terminar, especialmente en equipos compartidos.

Olvidé mi contraseña

  1. En la pantalla de acceso selecciona ¿Olvidaste tu contraseña?.
  2. Indica tu correo. Por seguridad la respuesta es la misma exista o no una cuenta.
  3. Abre el enlace recibido —dura 60 minutos y se usa una sola vez— y define una contraseña nueva.

Al cambiar la contraseña, todas las sesiones abiertas de la cuenta se cierran automáticamente.

Mi perfil

Desde el panel personal puedes actualizar datos de perfil y cambiar la contraseña. Mantén tu correo correcto: es el canal de invitaciones, restablecimiento y comprobantes.

Usuario

Comprar una evaluación

El catálogo muestra únicamente productos activos. Cada producto está vinculado a una prueba o evaluación configurada por el administrador.

  1. En la página inicial elige una evaluación y selecciona Comprar.
  2. Revisa el resumen: producto, precio, impuestos y, si aplica, captura un cupón.
  3. Inicia sesión o crea la cuenta directamente durante la compra.
  4. Confirma el pago mediante el método habilitado. Al completarse, se crea una asignación en Mis evaluaciones.
  5. Consulta el pedido en Mis compras; desde allí puedes abrir o descargar el comprobante PDF.
Cupones. Un cupón puede tener vigencia, límite global, límite por persona, monto mínimo y productos específicos. Que un código exista no garantiza que aplique a tu compra.

Usuario

Responder una evaluación

Una evaluación puede llegar por compra o por una asignación enviada por un administrador. En ambos casos aparece en Mis evaluaciones.

  1. En el panel personal, localiza la evaluación disponible y selecciona Comenzar.
  2. Lee las instrucciones y completa los datos demográficos solicitados, si los hay.
  3. Responde cada reactivo. Según la prueba, verás preguntas de opciones, pares de elección forzada o escalas Likert.
  4. Avanza entre las secciones y verifica las respuestas antes del envío.
  5. Selecciona Enviar para terminar. El sistema calcula y guarda el resultado según la configuración vigente.

Durante la aplicación

  • Las respuestas se guardan durante el avance; no cierres el navegador ni cambies de equipo sin confirmar que quedaron registradas.
  • Usa Pausar si necesitas detenerte. El intento quedará en pausa para retomarlo posteriormente.
  • Las preguntas pareadas requieren elegir una afirmación como “más” y otra como “menos” conforme a las instrucciones.
  • Tras enviar o finalizar, no podrás editar respuestas. Un administrador puede reabrir un intento cuando tenga autorización para hacerlo.
Recomendación. Contesta en un lugar estable, con conexión confiable y sin actualizar la página mientras se registra una respuesta.

Usuario

Resultados, reportes y comprobantes

Cuando un intento finaliza, el resultado aparece en el panel o se abre desde el enlace posterior a la evaluación. La vista presenta el resumen de valores calculados y la información disponible para tu cuenta.

  • Consulta únicamente tus resultados, salvo que un administrador te haya dado otro acceso autorizado.
  • Cuando el reporte está listo, puedes abrirlo o descargarlo como PDF.
  • Los reportes se generan desde una configuración versionada: los cambios posteriores no alteran el documento ya emitido.
  • En Mis compras, abre el pedido para ver el comprobante de la transacción.
Nota de interpretación. Los resultados son información del sistema. La interpretación profesional depende de la prueba, sus normas publicadas y el criterio del profesional responsable.

Administración

Centro de control

Al entrar a Administración se muestra el resumen ejecutivo. La navegación lateral reúne los módulos y la búsqueda superior permite localizar usuarios, evaluaciones activas, resultados y accesos a módulos con al menos dos caracteres.

Métricas

Usuarios activos, evaluaciones en curso o en pausa, evaluaciones finalizadas y baremos publicados.

Flujo de evaluaciones

Gráfica de actividad de los últimos 14 días con iniciadas y completadas.

Requieren atención

Prioriza intentos pausados o alertas operativas; abre el elemento para actuar.

Actividad reciente

Acceso directo a las evaluaciones concluidas y sus resultados.

Los módulos que ve cada persona dependen de sus permisos. Si un botón o acción no aparece, solicita a un superadministrador que revise tu rol.

Administración

Usuarios, invitaciones y asignaciones

Crear e invitar a una persona

  1. Abre Usuarios y selecciona Crear usuario.
  2. Captura nombre, apellidos, correo y los roles necesarios.
  3. Guarda. Se genera una invitación de un solo uso para establecer la contraseña.
  4. Si el correo está disponible, la invitación se envía; si no, configura SMTP y usa Reenviar invitación.

El enlace de invitación dura 48 horas. Las contraseñas nunca se envían por correo.

Asignar una prueba

  1. Busca al usuario y abre su detalle.
  2. En asignaciones, selecciona la prueba publicable o disponible y confirma.
  3. Revisa la asignación creada y, si corresponde, reenvía la invitación de aplicación.
  4. La persona verá la prueba en Mis evaluaciones al iniciar sesión.

Administración

Pruebas, versiones y reactivos

Este módulo administra la estructura de los instrumentos. Trabaja siempre con versiones: la publicación fija una versión y protege el historial de aplicaciones.

Crear y publicar una prueba

  1. Abre Pruebas y reactivos y crea una prueba con su nombre, código y datos básicos.
  2. Crea una versión en borrador, vacía o clonada de otra versión.
  3. Captura o reemplaza el contenido: secciones, instrucciones, preguntas y opciones.
  4. Valida la versión para identificar faltantes o inconsistencias.
  5. Publica solo después de revisar todo. La versión publicada se vuelve inmutable.

Importar el libro del cliente (DPO)

En la versión de borrador, usa la importación de archivo para el libro XLSM/XLSX autorizado. El importador requiere las hojas BaseResultados y Puntuación, acepta archivos de hasta 15 MB y comprueba estructura, pares, polaridades, escalas y puntuaciones.

Validación obligatoria. La importación no publica la prueba ni ejecuta el motor psicométrico. Revisa las advertencias, en especial las discrepancias de reactivos Likert, antes de publicar.

Estados y reglas

Estado / acciónUso
BorradorSe puede editar, importar, validar y preparar.
PublicadaContenido estable para nuevas aplicaciones; no se edita directamente.
ArchivadaSe conserva como historial y deja de ser la versión vigente.
Clonar versiónCrea un punto de partida editable para cambios posteriores.

Administración

Seguimiento de evaluaciones

Evaluaciones muestra los intentos en curso, pausados y finalizados. Filtra o busca para ubicar una persona, abre su diagnóstico y revisa estado, respuestas registradas, inicio, última actividad, duración y resultado asociado.

Reanudar un intento

  1. Ubica el intento que requiere atención y abre el diagnóstico.
  2. Comprueba la persona, la prueba y el estado antes de actuar.
  3. Selecciona Reanudar intento y confirma.
  4. Indica al participante que vuelva a iniciar sesión y abra la evaluación asignada.
Precaución. Reabrir un intento es una decisión operativa. Úsalo para atender una incidencia real; no debe emplearse para modificar respuestas ya finalizadas sin un procedimiento autorizado.

Administración

Resultados y reportes

En Resultados y reportes consulta el historial calculado, aplica filtros y abre el detalle de una corrida. La ficha permite revisar el contexto de aplicación, valores, norma usada y la trazabilidad de cálculo.

  • Usa el resumen para identificar volumen y disponibilidad de resultados.
  • Abre un resultado para consultar detalle y auditoría.
  • Cuando sea necesario y esté autorizado, recalcula el resultado indicando la configuración correspondiente; el sistema conserva la relación con la corrida anterior.
  • Genera, descarga o envía el reporte PDF solo cuando el estado indique que está listo.

Reporte de evaluación

Los reportes se almacenan con estado de generación. Si falla, revisa configuración de reporte, datos y correo antes de reintentar. El envío por correo queda registrado por destinatario, origen y estado.

Administración

Normas y matrices

Las normas son conjuntos versionados que contextualizan puntuaciones. El módulo permite crear, importar, editar, validar, revisar, aprobar, publicar, archivar y comparar versiones.

  1. Crea un conjunto de normas o importa la base autorizada.
  2. Abre la versión de trabajo y configura objetivos y umbrales.
  3. Ejecuta Validar; atiende todos los problemas reportados.
  4. Envía a revisión y solicita la aprobación de la persona con permiso correspondiente.
  5. Publica una vez aprobada. Antes de hacerlo, usa la vista de impacto para anticipar efectos.
EtapaPermiso necesarioFinalidad
Crear / editarnorm.create, norm.editDefinir conjunto, versión, objetivos y umbrales.
Validar / revisarnorm.reviewDetectar incoherencias y preparar revisión.
Aprobarnorm.approveDar autorización formal a la versión.
Publicar / archivarnorm.publish, norm.archiveControlar qué versión queda activa y conservar historial.

Administración

Pagos, catálogo y cupones

Productos y precios

  1. En Pagos y catálogo, crea el producto con código, URL amigable, nombre, descripción y prueba vinculada.
  2. Activa el producto y establece su orden de presentación.
  3. Registra un precio. Cada cambio crea una versión de precio y conserva el historial.
  4. Revisa el catálogo público antes de comunicarlo a clientes.

Cupones

Crea códigos con descuento porcentual o fijo. Define límites de uso, compra mínima, periodo de vigencia y productos aplicables. Desactiva el cupón en vez de reutilizar códigos con otro significado.

Pedidos y reembolsos

Filtra pedidos por estado y abre su detalle para revisar artículos, pagos y asignación. El reembolso exige el permiso payments.refund; ejecútalo únicamente después de validar la política y el pago correspondiente.

Administración · acceso restringido

Report Studio

Report Studio crea plantillas de reporte en versiones, vincula datos de resultados y genera PDFs. El acceso requiere admin.access y report_studio.manage; el superadministrador puede concederlos a un rol autorizado.

  1. Abre Report Studio y crea una plantilla con su código, nombre y descripción.
  2. Abre una versión para editar su diseño, tema y contenido. Usa el catálogo de componentes y la vista previa.
  3. Configura los enlaces de datos (bindings) para que los elementos tomen valores del resultado correcto.
  4. Guarda una revisión antes de cambios importantes; puedes consultar revisiones y restaurar una de ellas.
  5. Vincula la plantilla a la prueba o evaluación correspondiente, idioma y audiencia.
  6. Publica la versión cuando no queden bindings pendientes. Para cambios futuros, clona la versión.
  7. Genera el PDF desde la versión o desde la corrida de resultado indicada.
Activos. Puedes cargar recursos de hasta 5 MB por archivo. Verifica que el material tenga derechos de uso y que se vea correctamente en la vista previa antes de publicarlo.

Configurar SMTP

  1. Abre Configuración → Servidor de correo SMTP.
  2. Introduce host, puerto, usuario, contraseña y remitente.
  3. Guarda; la contraseña queda cifrada y no vuelve a mostrarse.
  4. Selecciona Probar conexión y envío. La prueba verifica conexión, TLS, autenticación y envío al remitente.

Administración

Roles y permisos

Un rol agrupa permisos; una persona puede tener varios roles y hereda la unión de sus permisos. Los permisos protegen acciones específicas del backend, por ejemplo users.read o mail.settings.manage.

RolTratamiento
SUPERADMINTiene acceso total. Es protegido: no puede editarse ni eliminarse.
ADMINRol de sistema editable en permisos, pero no eliminable.
USERRol de sistema editable en permisos, pero no eliminable.
PersonalizadoPuede crearse y eliminarse, siempre que no tenga usuarios asignados.

Crear un rol personalizado

  1. Abre Configuración → Roles.
  2. Crea el rol con código único, nombre y descripción clara.
  3. Selecciona solo los permisos requeridos para la función.
  4. Guarda y asígnalo a usuarios desde el módulo Usuarios.
Principio de mínimo privilegio. No concedas permisos administrativos “por si acaso”. Los permisos efectivos se actualizan al renovar la sesión.

Buenas prácticas

Seguridad, privacidad y operación responsable

Para administradores

  • Usa cuentas individuales; no compartas credenciales.
  • Revisa roles antes de asignarlos y deshabilita cuentas que ya no deben acceder.
  • Protege las credenciales de Stripe, SMTP y base de datos; nunca las copies a documentos públicos.
  • Revisa el estado del servidor y los intentos que requieren atención.
  • Conserva respaldos de base de datos y reportes generados.

Para todos los usuarios

  • Usa una contraseña única y no la compartas.
  • Verifica el dominio antes de abrir enlaces de correo.
  • Cierra sesión al usar equipos ajenos.
  • No compartas reportes con datos personales sin autorización.
  • Comunica errores de acceso al administrador o soporte.

La plataforma registra acciones administrativas relevantes para auditoría. Las versiones publicadas y las corridas de resultado preservan contexto para evitar cambios retroactivos sobre el historial.

Operación técnica

Referencia para instalación y mantenimiento

La plataforma es un monorepo con frontend Next.js, API NestJS y MySQL con Prisma. No usa Docker.

Requisitos y servicios

  • Node.js 20.9 o superior (se recomienda Node.js 24 LTS) y npm 11.
  • MySQL 8 con base de datos crevantia.
  • Desarrollo: frontend en http://localhost:3000; API en http://localhost:4000/api/v1; salud en /api/v1/health.

Arranque local

  1. Crea backend/.env y frontend/.env.local desde sus archivos de ejemplo.
  2. Ejecuta npm install, npm run db:generate, npm run db:migrate -- --name nombre_del_cambio y npm run db:seed.
  3. Inicia con npm run dev y comprueba GET /api/v1/health.

Comandos de mantenimiento

ComandoUso
npm run buildCompila frontend y backend.
npm run lint / npm run typecheck / npm testValidaciones de calidad.
npm run db:statusConsulta estado de migraciones.
npm run db:deployAplica migraciones existentes en producción.
npm run db:seedCarga datos iniciales/demostrativos; úsalo en el primer despliegue, no como sustituto de migraciones.
Producción. No ejecutes prisma db push ni prisma migrate dev. Aplica migraciones versionadas con npm run db:deploy, realiza respaldo previo y conserva también los PDFs/reportes privados.
